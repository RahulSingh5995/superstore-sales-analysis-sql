# 📊 Superstore Sales Analysis | SQL + Power BI

## 📌 Project Overview

This project analyzes the Superstore Sales dataset to identify key business insights related to sales, profit, products, customers, and regions. The project demonstrates an end-to-end data analytics workflow, starting from data cleaning and SQL analysis to building an interactive Power BI dashboard.

---

## 🎯 Objectives

- Clean and validate raw sales data
- Perform business analysis using SQL
- Identify sales and profit trends
- Analyze regional and category performance
- Build an interactive Power BI dashboard for business decision-making

---

## 💡 Key Business Insights

- Technology category generated the highest sales.
- Consumer segment contributed the highest overall profit.
- Sales varied across regions, highlighting regional performance differences.
- Monthly sales trend helps identify seasonal business patterns.
- Dashboard enables quick monitoring of overall business performance.
