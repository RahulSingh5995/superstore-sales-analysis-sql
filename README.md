# Superstore Sales Analysis using SQL

## Project Overview

This project analyzes a retail Superstore dataset using MySQL.

The objective is to answer real business questions by writing SQL queries that generate actionable insights about sales performance, customers, products, regions, and profitability.

---

## Skills Demonstrated

- SQL
- Aggregate Functions
- GROUP BY
- ORDER BY
- WHERE
- HAVING
- COUNT(DISTINCT)
- Business KPI Analysis
- Customer Analytics
- Segment Analysis
- Profit Margin Calculation

---

## Dataset

- Sample Superstore Dataset
- Total Records: 9,694
- Total Orders: 4,931
- Total Customers: 793
